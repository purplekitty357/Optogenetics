광유전학 1형 당뇨 시뮬레이터

빛 자극으로 인슐린을 분비시키는 방식과 피하 인슐린 주사 방식의 혈당 곡선을 같은 조건에서 비교합니다. Δt = 1분, 전진 오일러법, 0~360분.

요약

혈중 인슐린

cAMP 상대값

빛이 켜지면 bPAC가 cAMP를 만들고, 빛을 꺼도 τ=23초에 걸쳐 서서히 줄어듭니다.

단백질 구조 뷰어

빛이 ChR2를 열면 → 인슐린이 나와서 → 인슐린 수용체에 붙는다.

계산식 · 가정 · 출처

매 1분마다 계산하는 순서
  1. 식사 포도당 흡수 (두 방식 공통) — dRa1/dt = −(Ra1 − AG·uCHO)/tmaxG, dRa/dt = −(Ra − Ra1)/tmaxG
  2. A. 광유전학 — A = L/(L + K0.5), d[cAMP]/dt = (A·cAMPmax − [cAMP])/τcAMP, ISR = ISRbase·(1 + (fmax−1)·[cAMP]/cAMPmax)·G/(G + 150)
  3. B. 주사 — dS1/dt = u − S1/tmaxI, dS2/dt = (S1 − S2)/tmaxI, dI/dt = S2/(VI·tmaxI) − ke·I
  4. 인슐린 작용 지연 (공통) — dX/dt = −p2·X + p2·SI·I
  5. 혈당 갱신 (공통) — dG/dt = −(SG + X)·G + SG·Gb + Ra/(V·체중)

ISR 식 마지막 항 G/(G+150)이 포도당 의존성, 즉 저혈당 안전장치입니다. 혈당이 낮아지면 빛을 계속 켜도 분비가 줄어듭니다.

ChR2의 τoff = 11 ms는 1분 단위 계산에서 사실상 0이므로, 빛 ON/OFF는 즉시 반영되는 것으로 단순화했습니다. 이 단순화의 근거로 값만 표에 남깁니다.

사양서에 없어서 직접 정한 값 — 보고서에 반드시 밝힐 것
  • 조직 투과율 (기본 0.74%) — 광 세기 슬라이더는 피부 표면 단위(mW/cm²)인데 K0.5는 세포 표면 단위(μW/mm²)입니다. 50 mW/cm²를 그대로 넣으면 500 μW/mm²로 K0.5의 135배라 A가 항상 1에 붙어 슬라이더가 무의미해집니다. 그래서 표면에서 세포까지의 감쇠를 투과율로 두었고, 기본값은 50 mW/cm²에서 A = 0.5가 되도록 잡았습니다. 문헌값이 아닌 가정값이며 슬라이더로 바꿔볼 수 있습니다.
  • ISRbase — 사양서에 수치가 없습니다. 빛을 끈 상태에서 초기 혈당일 때의 분비량이 기저 주입률 ub와 같아지도록 맞췄습니다. 세 방식이 똑같은 인슐린 상태에서 출발해야 비교가 공정하기 때문입니다.
  • Gb — 초기 혈당이 t=0에서 변하지 않도록 Gb = G₀·(SG + X₀)/SG로 역산했습니다. 기저 인슐린이 깔린 상태에서 환자가 초기 혈당에 머물러 있다는 뜻입니다.
  • cAMPmax = 1 — ISR 식에 [cAMP]/cAMPmax 비율로만 들어가므로 상대값 1로 두었습니다. 그래프의 cAMP는 0~1 상대값입니다.
  • 기저 인슐린 처리 — 대조군과 주사 방식은 ub를 피하 경로로 계속 받고, 광유전학은 ub 대신 빛을 받는 세포가 분비를 담당합니다. 대조군은 "기저 인슐린만, 식사 보정 없음"입니다.
  • cAMP는 1초 간격으로 계산 — τcAMP = 23초라 1분 간격 오일러법은 발산합니다(Δt/τ = 2.6). 빛과 cAMP만 1초 간격 내부 루프로 계산하고 그 분의 평균을 ISR에 넣습니다. ON/OFF 시간이 초 단위이므로 이 방식이 점등 주기도 정확히 반영합니다. 혈당·인슐린 본체는 사양서대로 1분 간격입니다.
  • 쓰이지 않은 상수 — k12, ka1~kb3, EGP0, F01은 Hovorka 모델 상수입니다. 사양서의 계산 순서 1~5단계는 Bergman 계열 식이라 이 상수들을 쓰지 않습니다. 지시대로 코드에 선언하고 출처만 달아두었습니다.
