광유전학을 통한 1형 당뇨병 치료 시뮬레이터

빛 자극 → β세포 활성화 → 인슐린 분비 → 혈당 감소 과정을 시간에 따라 반복 계산하고, 주사 방식과 비교합니다.

결과 비교

사용한 수식

  • 빛 활성화 (2.1): dA/dt = kon·L(t)·(1-A) - koff·A
  • 빛-인슐린 분비 (2.2, 2.3): u_light = u_basal + α·A·G / u_basal + α·A / u_basal + α·A·SG(G), SG(G) = Smax·G^n/(G50^n+G^n)
  • 혈중 인슐린 (1.1): dI/dt = -n(I - Ib) + u(t)
  • 혈당 (1.1): dG/dt = Rfood - p1(G - Gb) - X·G, dX/dt = -p2·X + p3(I - Ib)
  • 혈당 (2.4): dG/dt = Rfood - kbasal·G - kinsulin·I·G
  • 식사 (1.2): Rfood = UG(t)/VG, UG(t) = DG·AG·t·e^(-t/tmax,G)/tmax,G²
  • 주사 (1.3): dS1/dt = u - S1/tmax,I, dS2/dt = S1/tmax,I - S2/tmax,I, U = S2/tmax,I
  • 주사 (2.5): dSsc/dt = -ka·Ssc + Dinj·δ(t-tinj), dI/dt = ka·Ssc - ke·I (ke = n)
  • 계산: 오일러 방법으로 Δt = 0.5분마다 값(t+Δt) = 값(t) + 변화율·Δt 를 반복합니다.
  • 파라미터 기본값은 자료에 수치가 없어 시연용으로 정한 값입니다. 광유전학 부분(2.x)은 실제 논문 공식이 아닌 임의 변형 모델입니다.
