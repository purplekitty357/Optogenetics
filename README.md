# 광유전학 1형 당뇨 시뮬레이터

빛 자극으로 인슐린을 분비시키는 방식과 피하 인슐린 주사 방식의 혈당 곡선을
같은 조건에서 겹쳐 비교하는 단일 HTML 시뮬레이터입니다.
"광유전학 1형 당뇨 시뮬레이터 — Claude Code 요청 사양서"(2026-10-28)를 구현했습니다.

## 실행
`index.html` 을 브라우저로 열면 됩니다. 설치는 필요 없지만, Chart.js와 3Dmol.js를
CDN에서 불러오므로 **인터넷 연결이 필요**합니다.

## 구성
- 왼쪽 — 조작부: 광 자극 / 주사 / 환자 / 식사 설정, 각 슬라이더에 값·단위·출처와 ⓘ 툴팁
- 가운데 — 혈당 그래프: 광유전학·주사·대조군 세 곡선, 정상 범위(70~180) 음영
- 오른쪽 — 보조 그래프: 혈중 인슐린, cAMP 상대값
- 그래프 아래 — 결과 해석: 지금 설정에서 왜 이런 곡선이 나왔는지 자동 설명
- 아래 — 광유전학 단백질과 작동 원리: bPAC(이 모델)와 ChR2(다른 방식) 비교,
  구조 뷰어 OaPAC(5X4U) / 인슐린(4INS) / 인슐린 수용체(6SOF) / ChR2(6EID) 탭
- 맨 아래 — 계산식, 고정 상수표, 직접 정한 값, 출처 목록

## 계산
Δt = 1분, 전진 오일러법, 0~360분. 매 분마다 사양서의 1~5단계를 순서대로 실행합니다.
두 방식은 인슐린이 어디서 오는지만 다르고 3~5단계(인슐린 작용·혈당 갱신)는 완전히 동일합니다.

## bPAC와 ChR2는 다른 방식입니다
이 시뮬레이터의 계산식은 **bPAC** 기반입니다.

| | 작동 원리 | 이 모델에서 |
|---|---|---|
| **bPAC** | 빛 → bPAC 활성화 → cAMP 증가 → 포도당 자극에 의한 인슐린 분비 **증폭** | **계산식이 쓰는 방식** |
| ChR2 | 빛 → 양이온 통로 개방 → 막 탈분극 및 Ca²⁺ 신호 변화 → 인슐린 분비 촉진 | 쓰이지 않음 (참고용) |

f_max=5.0 시나리오(Reinbothe 2014)만 ChR2 실험에서 나온 값이고, 나머지 계산식은 전부 bPAC 기준입니다.

## 자가면역 반응과 β세포 손상 — 전부 가상값
1형 당뇨는 면역세포가 자기 β세포를 공격하는 자가면역질환입니다.
빛으로 분비를 촉진해도 β세포가 계속 손상되면 치료 효과가 제한되는데, 이 한계를 보여주는 기능입니다.

- **면역 공격 강도**: 없음 / 약함(k=0.0008) / 강함(k=0.0025)
- **초기 기능성 β세포 비율 β₀**: 10~100%
- β(t) = β₀·e^(−kt) 를 **빛에 의한 분비 ISR에만** 곱합니다.
  주사 인슐린은 살아 있는 세포가 없어도 작용하므로 곱하지 않습니다.

이 차이 때문에 β세포가 줄면 광유전학만 효과가 떨어지고 주사는 그대로입니다.
β₀를 30% 정도로 낮추면 광유전학이 대조군보다도 나빠지는데, 광유전학은 기저 인슐린까지
β세포가 담당하기 때문입니다. **세포가 사라지면 빛을 쪼일 대상 자체가 없다**는 뜻입니다.

> 감소율 k와 β(t) 식은 **논문에서 가져온 값이 아니라 임의로 정한 가상값**입니다.
> 실제 β세포 파괴는 수개월~수년에 걸쳐 일어나지만, 6시간 창에서 눈에 보이도록 시간을 압축했습니다.
> 보고서에 반드시 가상값임을 밝혀야 합니다.

## 불확실성 시나리오
인슐린 분비 배수 f_max는 연구마다 값이 갈려 단일 숫자로 못 박지 않고 세 버튼으로 처리합니다.

| 시나리오 | f_max | 근거 |
|---|---|---|
| 보수적 (하한) | 2.0 | Chen 2024, 사람 베타세포 EndoC-βH3 |
| 대표값 | 3.5 | Zhang & Tzanakakis 2017, MIN6·마우스 췌도 |
| 낙관적 (상한) | 5.0 | Reinbothe 2014, ChR2 발현 췌도 |

세 곡선을 동시에 겹쳐 그리고, 상한~하한 사이를 반투명 밴드로 칠해 범위를 보여줍니다.

## 사양서에 없어서 직접 정한 값 — 보고서에 반드시 밝힐 것
화면 맨 아래 "사양서에 없어서 직접 정한 값" 항목에 같은 내용이 정리되어 있습니다.

1. **조직 투과율 (기본 0.74%)** — 광 세기 슬라이더는 피부 표면 단위(mW/cm²)인데
   K₀.₅는 세포 표면 단위(μW/mm²)입니다. 50 mW/cm²를 그대로 넣으면 500 μW/mm²로
   K₀.₅의 135배라 활성도 A가 항상 1에 붙어 슬라이더가 무의미해집니다.
   표면에서 세포까지의 감쇠를 투과율로 두었고, 기본값은 50 mW/cm²에서 A = 0.5가
   되도록 잡았습니다. **문헌값이 아닌 가정값**이며 슬라이더로 바꿀 수 있습니다.
2. **ISR_base** — 사양서에 수치가 없습니다. 빛을 끈 상태에서 초기 혈당일 때의
   분비량이 기저 주입률 ub와 같아지도록 맞췄습니다(세 방식이 같은 인슐린 상태에서 출발).
3. **Gb** — 초기 혈당이 t=0에서 변하지 않도록 Gb = G₀·(SG + X₀)/SG로 역산했습니다.
4. **cAMP_max = 1** — ISR 식에 비율로만 들어가므로 상대값 1로 두었습니다.
5. **기저 인슐린 처리** — 대조군·주사는 ub를 피하 경로로 계속 받고, 광유전학은
   ub 대신 빛을 받는 세포가 분비를 담당합니다. 대조군은 "기저 인슐린만, 식사 보정 없음"입니다.
6. **cAMP만 1초 간격으로 계산** — τ_cAMP = 23초라 1분 간격 오일러법은 발산합니다(Δt/τ = 2.6).
   빛과 cAMP만 1초 간격 내부 루프로 계산하고 그 분의 평균을 ISR에 넣습니다.
   ON/OFF 시간이 초 단위이므로 이 방식이라야 점등 주기도 정확히 반영됩니다.
   혈당·인슐린 본체는 사양서대로 1분 간격입니다.
7. **점등 방식 3가지** — 사양서의 "1회 조사 시간"과 "ON/OFF 시간"은 서로 다른 자극
   프로토콜이라 연속 / 간헐 / 단일 펄스 중 선택하게 했습니다. 기본은 연속(Zhang 2017의 30분 조사).
8. **자가면역 β세포 감소** — 위 "자가면역 반응과 β세포 손상" 항목의 k와 β(t) 식 전부가 가상값입니다.
9. **β₀ < 100%이면 출발점이 달라집니다** — ISR_base는 β=100%에서 기저 주입률과 같아지도록 맞춘 값이라,
   β₀를 낮추면 광유전학 쪽만 기저 인슐린이 적은 상태로 시작합니다. 세 방식의 출발점을 똑같이 두고
   비교하려면 β₀를 100%, 면역 공격을 "없음"으로 두세요.
10. **쓰이지 않은 상수** — k12, ka1~kb3, EGP0, F01은 Hovorka 모델 상수입니다.
   사양서의 계산 순서 1~5단계는 Bergman 계열 식이라 이 상수들을 쓰지 않습니다.
   지시대로 코드에 선언하고 출처만 달아두었습니다.

## 시뮬레이션 결과의 의미와 한계
화면 맨 위에도 같은 안내가 띄워져 있습니다.

> 본 시뮬레이터는 광유전학과 인슐린 주사 방식의 혈당 조절 **원리를 비교**하기 위한 교육용 모델입니다.
> 실제 환자의 혈당 변화나 치료 효과를 정확하게 예측하는 프로그램이 아니며,
> 계산 결과는 설정한 수학적 조건과 가정값에 따라 달라집니다.
> 그래프에서 광유전학이 주사보다 효과적으로 보이더라도 실제 환자에게 같은 결과가 나타난다고 판단할 수 없습니다.
> **인슐린 주사는 임상에서 검증된 표준 치료법이지만, 광유전학을 이용한 인슐린 분비 조절은
> 아직 세포·동물 수준의 연구 단계입니다.**

## 알아둘 점
사양서의 V = 0.9 dL/kg는 흔히 쓰이는 값(약 1.6 dL/kg)보다 작아 식사 1회가 올릴 수 있는
혈당 총량이 커집니다. 그래서 최고 혈당이 임상에서 보는 값보다 높게 나옵니다.
사양서 지시대로 V를 바꾸지 않았고, 이 값은 세 곡선에 똑같이 적용되므로 방식 간 비교에는
영향이 없습니다. 화면의 요약표 아래에도 같은 안내가 현재 설정 기준으로 표시됩니다.
