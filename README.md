# 광유전학을 통한 1형 당뇨병 치료 시뮬레이터

빛 자극 → β세포 활성화 → 인슐린 분비 → 혈당 감소 과정을 단순화한 수식으로 시간에 따라 반복 계산하고,
인슐린 주사 방식과 혈당 변화를 비교하는 시뮬레이터입니다.

## 실행
`index.html` 을 브라우저로 열면 됩니다. (설치 필요 없음)

## 파일
- `model.js` : 수식과 반복 계산(오일러 방법, Δt = 0.5분)
- `index.html` : 조절 슬라이더, 그래프, 결과 비교 표

## 사용한 수식 (정리 문서 번호 기준)
| 번호 | 내용 | 구분 |
|---|---|---|
| 1.1 | Bergman minimal model (혈당 G, 인슐린 작용 X, 혈중 인슐린 I) | 실제 논문 |
| 1.2 | 식사 후 포도당 흡수 UG(t) | 실제 논문 |
| 1.3 | 피하주사 인슐린 2구획 흡수 | 실제 논문 |
| 2.1 | 빛 활성화 dA/dt = kon·L·(1-A) - koff·A | 임의 변형 |
| 2.2 | 빛-인슐린 분비 u_light = u_basal + α·A (또는 α·A·G) | 임의 변형 |
| 2.3 | Hill 함수 분비 포화 SG(G) | 임의 변형 |
| 2.4 | 단순 혈당식 dG/dt = Rfood - kbasal·G - kinsulin·I·G | 임의 변형 |
| 2.5 | 피하주사 1구획 흡수 | 임의 변형 |

Hovorka 모델(1.4)은 x1, x2, x3 및 각종 파라미터의 정의가 자료에 없어 사용하지 않았습니다.

## 참고
- 파라미터 수치는 자료에 없어 시연용으로 정한 값입니다.
- 1.2 식의 Rfood 는 UG(t) 를 포도당 분포 부피 VG 로 나눈 값으로 사용했습니다.
- 2.3 Hill 함수는 빛 분비식과 결합하여 `u_basal + α·A·SG(G)` 형태로 사용했습니다.
